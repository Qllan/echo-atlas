# ECHO — Увидеть. Исследовать. Понять.

**ECHO** — интерактивный атлас Вселенной и конкурсный проект SiteHack. Вместо стандартного каталога со статьями посетитель начинает с вопроса, проводит наблюдение в учебной модели, проверяет гипотезу и сохраняет результат.

## Демо

Рабочий сайт: [echoatlas.ru](https://echoatlas.ru/) (хостинг SprintHost).

## Что есть в проекте

- 13 космических объектов; интерактивные 3D-сцены с резервными 2D-схемами.
- Исследования фаз Луны, тени колец Сатурна и импульсов пульсара.
- Локальный блокнот открытий и экспорт.
- Адаптивная навигация для телефонов и режим уменьшенной анимации.

## Локальный запуск

Откройте [`index.html`](index.html) в современном браузере. Это автономный HTML: Three.js и текстуры встроены, сборка и сервер не требуются.

При некоторых настройках безопасности браузера для корректного запуска локального файла может понадобиться простой HTTP-сервер, например `python -m http.server 8000`.

## Размещение

Для SprintHost достаточно положить `index.html` в папку `public_html`. GitHub Pages тоже поддерживает статическую версию, но домен `echoatlas.ru` в настоящее время обслуживается отдельным хостингом; не меняйте DNS без необходимости.
